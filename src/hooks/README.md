# CRUD Usuarios React

## Tecnologías

- React
- Vite
- Bootstrap
- Axios
- Docker

## Instalación

### Backend

### bash
git clone https://github.com/JGarcia55/users-api
cd users-api
docker compose up --build

### Frontend
npm install
npm run dev


## Funcionalidades

- Crear usuarios
- Listar usuarios
- Editar usuarios
- Eliminar usuarios
- Validaciones de formulario
