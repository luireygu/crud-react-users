CRUD de Usuarios - React + Vite
Descripción

Aplicación desarrollada en React utilizando Vite para consumir una API REST de usuarios ejecutada mediante Docker.

La aplicación permite realizar las operaciones CRUD:

Crear usuarios
Consultar usuarios
Editar usuarios
Eliminar usuarios
Tecnologías utilizadas
React
Vite
Axios
Bootstrap
Docker
Ejecución del Backend

Ubicarse en la carpeta del backend y ejecutar:

docker compose up --build
Ejecución del Frontend

Instalar dependencias:
npm install

Nota: no se adjunta el node_modules IMPORTANTE!!!
